# 예측 모델 (ranking-v3)

`lib/core/services/prediction_engine.dart` 의 계수를 만들어 낸 학습 파이프라인입니다.
엔진의 숫자를 손으로 바꾸지 말고, 여기서 재학습한 결과를 옮겨 적으세요.

## 모델

경주 안에서 1착 → 2착 → 3착을 차례로 고르는 **Plackett-Luce 랭킹 모델**입니다.
선수별 효용 `u = Σ(계수 × 피처)` 를 구해 내림차순이 예측 순위가 되고,
`softmax(u / 온도)` 가 예상 승률이 됩니다. softmax 는 평행이동에 불변이라
절편이 필요 없고, 값이 없는 피처를 학습 평균으로 채우면 경주 안 모든 선수에게
같은 값이 더해져 순위가 흔들리지 않습니다.

## 피처

공공데이터포털 출주표(RACE_DOC)와 KBOAT 확정출주표에서 **같은 정의로** 얻을 수
있는 값만 씁니다. 이 제약이 없으면 학습 때 본 지표와 실제 예측 때 읽는 지표가
달라집니다. 실제로 KBOAT 출주표에는 `최근 6회차` 와 `연간` 컬럼이 함께 있어,
연간 컬럼을 읽도록 파서를 맞춰 두었습니다.

| 피처 | RACE_DOC | KBOAT 확정출주표 |
| --- | --- | --- |
| 코스 | `race_reg_no` | 정번 |
| 등급 | `racer_grd_cd` | 선수정보 |
| 선수 평균착순점 | `avg_rank` | 연간성적 평균착순점 |
| 선수 연대율 | `high_rate` | 연간성적 연대율 |
| 모터 평균착순점 | `mot_avg_rank_scr` | 모터성적 평균착순점 |
| 모터 이연대율 | `mot_high_rank_ratio` | 모터성적 이연대율 |
| 모터 삼연대율 | `mot_high_3_rank_ratio` | 모터성적 삼연대율 |
| 보트 평균착순점 | `boat_avg_rank_scr` | 보트성적 평균착순점 |
| 보트 연대율 | `boat_high_rank_ratio` | 보트성적 연대율 |

여기에 `1·2코스 × A급 선수` 상호작용을 더합니다.

### 제외한 것과 이유

- **단승 배당**: 경주가 끝난 뒤에만 공개돼 예측 시점에 얻을 수 없습니다.
  배당을 섞으면 홀드아웃 1착 적중이 58%까지 오르지만, 지난 경주를 다시 볼 때만
  가능한 수치라 실제 예측과 어긋납니다. 실시간 배당 경로를 확보하면 재검토할 값어치가 있습니다.
- **평균 ST**: RACE_DOC 에 90% 결측입니다.
- **평균득점**: 평균착순점과 거의 같은 정보라 계수 부호가 뒤집혔습니다(다중공선성).
- **체중·나이·사고점·F/L**: 검증 구간에서 개선이 없었습니다.

## 검증 방법

시간순 3분할로, 홀드아웃은 마지막에 한 번만 봅니다.

| 구간 | 기간 | 경주 수 | 용도 |
| --- | --- | --- | --- |
| 학습 | 2023-01 ~ 2024-12 | 3,536 | 계수 추정 |
| 검증 | 2025-01 ~ 2025-12 | 1,765 | 피처셋·정규화·softmax 온도 선택 |
| 홀드아웃 | 2026-01 ~ 2026-08 | 1,130 | 최종 평가 |

최종 계수는 선택이 끝난 뒤 학습+검증(5,301경주)으로 다시 학습합니다.

### 미래정보 누출 점검

RACE_DOC 의 통계는 해당 경주 **시점까지의 누적치**입니다. 같은 선수의 `win_ratio`
가 날짜에 따라 변하는 것을 확인했으므로(시즌 종료 후 스냅샷이 아님) 과거 경주를
평가하는 데 써도 됩니다.
